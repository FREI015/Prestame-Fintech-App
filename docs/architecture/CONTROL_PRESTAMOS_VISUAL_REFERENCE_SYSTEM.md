# Control Préstamos - Sistema Visual de Referencia

Fecha:
20260614-005552

## Dirección visual

La app debe parecerse al lenguaje gráfico de la referencia enviada:

- Encabezados azul oscuro.
- Fondo general claro.
- Tarjetas blancas compactas.
- Bordes suaves.
- Sombras sutiles.
- Acento turquesa.
- Estados con chips pequeños.
- Métricas limpias.
- Pantallas con menos ruido.
- Nada de tarjetas gigantes innecesarias.
- Nada de textos explicando que la app es premium.
- La app debe sentirse profesional por diseño.

## Reglas visuales

### Inicio

Debe tener:

1. Header oscuro compacto.
2. Saludo operativo.
3. Grid de 4 métricas pequeñas:
   - Total prestado.
   - Cobrado hoy.
   - Pagos pendientes.
   - Clientes activos.
4. Gráfico o tendencia mensual/semanal.
5. Próximos pagos.
6. Acciones principales al final:
   - Nuevo préstamo.
   - Registrar pago.
   - Clientes.

No debe tener:

- Tarjetas enormes.
- Exceso de explicación.
- Repetición de métricas.
- Bloques que digan "premium".
- Más de 2 niveles visuales compitiendo.

### Clientes

Debe tener:

1. Header oscuro.
2. Buscador blanco.
3. Lista limpia.
4. Avatar circular.
5. Nombre del cliente.
6. Número o referencia.
7. Estado pequeño.
8. Monto alineado a la derecha.

### Detalle del préstamo

Debe tener:

1. Header oscuro.
2. Tarjeta del cliente.
3. Resumen financiero 2 columnas.
4. Progreso de pago.
5. Plan de pagos compacto.
6. Transacciones recientes.
7. Dos acciones principales abajo.

### Configuración

Debe tener:

1. Header oscuro.
2. Tarjetas por sección.
3. Iconos circulares.
4. Texto breve.
5. Filas tipo settings.
6. Nada de textos largos.
