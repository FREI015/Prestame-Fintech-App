
# Coding Standards


## Kotlin


Usar:

- nombres descriptivos
- funciones pequeñas
- separación de responsabilidades


Evitar:

- lógica financiera en UI
- duplicación
- código muerto


## Compose


UI:

Solo representación.


ViewModel:

Estado y lógica de presentación.


Domain:

Reglas de negocio.


Data:

Persistencia.
